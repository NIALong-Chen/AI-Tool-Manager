# AI工具管理器 · 测试与验收说明

版本：1.0.0

## 测试层次

### 扫描测试：17 项

通过隔离文件树验证 Skills 与插件技能、TOML/JSONC MCP、明确禁用、附带模板、Git 与解压源码、下载文件、技能描述、YAML 折行、插件描述、GitHub URL 凭据清理、结果不含配置密钥/命令/含混状态、格式提示、稳定身份、读取前后文件哈希与数量不变、重叠范围去重、取消。

其中对未知插件启用值单独验证：不推断为“已禁用”或“已安装文件”。

### 原生集成测试：16 项

实际启动生成的 WPF EXE，验证：

1. 快捷方式创建逻辑在隔离目录运行。
2. 自动更新设置保存。
3. 自选目录保存并读取。
4. 真实文件扫描分类。
5. 桌面宽度下三列卡片。
6. 搜索筛选。
7. 整张卡片进入独立详情页。
8. 详情读取本地文档。
9. “本地位置”标签。
10. 返回保留搜索。
11. 手动刷新发现新增文件。
12. 最近变化记录新增。
13. FileSystemWatcher 真实事件触发更新。
14. 文档变化后重新读取。
15. 外部删除后清单更新。
16. 扫描没有删除其他文件。

原生测试会主动增删隔离材料来产生变化事件；这是测试准备行为，不是扫描器的默认行为。必须存在 .ai-manager-test 标记才能进入该模式。测试不会在真实桌面创建快捷方式。

### 独立发布验证

将 EXE 单独复制到没有 src 的新目录，再执行隔离扫描与截图，检查嵌入资源和启动能力，避免程序暗中依赖开发目录。

## 运行命令

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Run-Tests.ps1
~~~

窗口测试需要可用 Windows 桌面。测试输出会报告各项 PASS 和 JSON 报告位置；单独运行 Scanner.Tests.ps1 可以仅验证扫描器。

## 验收矩阵

| 用户需求 | 对应证据 |
| --- | --- |
| 不依赖 VS Code | 原生 EXE 独立复制启动 |
| 六类工具盘点 | 扫描夹具与本机读取验证 |

| 刷新发现新文件 | 隔离文件新增后手动刷新 |

| 返回保留筛选 | 搜索值与页面状态断言 |

| 可从桌面启动 | EXE 验证与隔离快捷方式创建 |

## 结果与限制

具体 1.0 测试结果保存于验证记录.json。文档不把尚未运行的 CI、Windows 10 设备测试或真实用户桌面快捷方式测试记为通过。

本机扫描内容、实际用户目录、配置和凭据不作为仓库测试材料。docs/images 的窗口图来自隔离示例文件，不代表任何用户的实际安装清单。
