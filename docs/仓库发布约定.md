# 仓库与发布约定

项目中文名：AI工具管理器
正式版本：1.0.0
版本标签：v1.0.0

## 源码仓库

仓库保存 README、产品设计、技术说明、验证说明、源码、构建脚本、测试材料生成脚本和交互原型。实际仓库路径以 GitHub 创建结果为准；不要把尚未创建的地址写成有效下载地址。

在未明确要求公开时，创建新远程仓库应采用私有可见性。许可证尚未选定，暂不自动加入开放源代码授权文本。

## 应排除的内容

- Data/settings.json 和 TestData 设置。
- 本机扫描清单、用户配置、Token、密码或凭据文件。
- 临时工作区、真实用户路径日志、构建中间文件。
- 可由源码生成的 EXE/ZIP；这些应作为版本发布文件分发，而不是源码历史。

## 版本一致性

VERSION 为 1.0.0；程序集、文件和 manifest 版本为 1.0.0.0；界面显示本地版 1.0。对外说明使用“1.0 版本 / v1.0.0”。

发布前运行构建与测试，核对单独复制的 EXE 可启动，重新计算 SHA-256。版本号相同但二进制变化时，需重新生成校验值和发布包。

## 远程状态

本地 Git 标签或本地归档不等于已在 GitHub 发布。只有远程仓库、提交、标签或 Release 实际可读取时，才报告上传/发布成功。连接中断时保留本地交付物，恢复后先检查远程是否已有同名项目或提交，避免重复创建。
