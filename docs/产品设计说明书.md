# AI工具管理器 · 产品设计说明书

文档版本：1.0.0
适用版本：Windows 桌面版 1.0
日期：2026-10-18

## 1. 产品定位

将分散在 AI 客户端、文件夹、下载目录和 Windows 应用登记中的工具集中盘点，让用户回答三个问题：本地有什么、每个条目目前是什么情况、如何开始使用。

1.0 以本地、只读、证据明确为核心，不将“存在文件”“写入配置”“已安装”和“能够运行”混为一谈。没有执行检查的项目，明确说明尚未检测的内容。

## 2. 目标用户与使用场景

- 同时使用 Codex、Claude Code 等客户端，难以记住 Skills 和插件位置的用户。
- 下载了 GitHub 工具或安装包，需要区分源码、归档和已安装应用的用户。
- 希望点击名称了解功能与使用方法，而不必逐个翻找目录的用户。

主要场景：首次建立清单；下载后刷新；添加自定义磁盘目录；查看工具说明和准确路径；比较本次会话的新增与变化。

## 3. 盘点对象

| 分类 | 识别依据 | 不作出的推断 |
| --- | --- | --- |
| Skills | SKILL.md | 客户端一定已加载或能调用 |
| MCP 服务 | 已知客户端配置，或附带配置文件 | 服务一定启用、已连接或有权限 |
| 插件 | 清单文件、编辑器扩展清单、插件启用配置 | 缓存存在等于已启用 |
| GitHub / 源码 | Git 标记，或 README 与项目清单 | 一定来自 GitHub、一定与 AI 有关或依赖齐全 |
| 独立软件 | Windows 应用登记或常见 PATH 入口 | 程序一定能启动 |
| 下载文件 | 安装程序与归档扩展名 | 文件一定可信、属于 AI 或已经安装 |

分类统计统计的是记录，不是经过去重归并的“可用产品总数”；同一工具的不同配置或路径可以形成不同记录。

## 5. 页面与交互

### 5.1 工具总览

顶部以六类工具展示数量。点击分类筛选，不将不同对象笼统归入“待验证”。支持名称、用途、客户端、路径搜索和客户端筛选。全部类型按钮清除分类选择；分页每页 30 条，统计与搜索覆盖全部结果。

卡片展示名称、类别/客户端、说明摘要、具体发现情况和未检测项。整张卡片可以点击，进入独立详情页。首页底部不常驻工具详情。

### 5.2 功能详情

展示名称、所属客户端与发现依据，包含两个标签：

- 功能与使用：功能说明、使用步骤或文档摘录、说明来源、阅读原始说明；存在明确 GitHub 来源时，可手动打开项目主页。
- 本地位置：准确路径、复制路径、打开所在文件夹、当前发现情况。

返回工具库时保留搜索、客户端筛选、分类和分页。查看文档仅显示纯文本，不执行文档中的指令。

### 5.3 管理目录

展示默认范围及自选目录。添加后保存到本工具设置并重新扫描。“停止扫描”只移除本工具的自选范围，不删除目录。窗口提供全量 JSON/CSV 导出。

### 5.4 最近变化

首次扫描建立基准，之后记录新发现、资料/状态变化、本次未再发现。仅记录本次应用会话，最多保留 250 条，避免无限增长。

“本次未再发现”可能由移动、删除、权限或读取失败造成，不能直接等同于“已经卸载”。

## 6. 状态表达

| 发现情况 | 用户可理解的含义 | 附加说明 |
| --- | --- | --- |
| 技能文件已找到 | 文件在本地 | 加载情况未检测 |
| 插件附带技能 | 技能位于插件目录 | 插件启用情况未检测 |
| 已写入客户端配置 | 已知配置位置存在服务项 | 尚未测试连接 |
| 配置中已禁用 | 配置中存在明确禁用布尔标记 | 不修改该状态 |
| 附带配置或示例 | 配置位于非标准位置 | 不推断已被客户端采用 |
| 插件文件已找到 | 本地有插件清单 | 启用情况未检测 |
| 配置标记为启用 | 插件配置启用标记为真 | 实际加载未检测 |
| 存在插件配置 | 有配置，但启用值无法明确识别 | 不推断安装文件存在 |
| 源码目录已找到 | 发现项目文件 | 依赖与启动未检查 |
| 系统中有安装记录 | 系统有应用登记 | 尚未启动检查 |
| 命令入口已找到 | PATH 中有入口文件 | 不保证依赖完整 |
| 安装包 / 归档文件已下载 | 文件在磁盘上 | 不代表已经安装 |

## 7. 刷新与自动更新

手动刷新重新读取范围内的文件、配置与文档。扫描在后台运行；取消保留上次完整清单。自动更新在软件打开且开关启用时生效：文件事件静默约 1.4 秒后重新盘点，并每 60 秒补充核对。

不注册后台服务，不在关闭后继续监控，不自动更新程序自身。下载到范围之外时，用户需先添加目录。

## 8. 功能说明来源

优先提取本地 SKILL.md、插件清单和 README。显示来源，并允许阅读原文。找不到说明时提供类型层面的操作引导，明确缺少可确认的具体文档；不能凭工具名称编造功能。英文原始资料按原文展示，1.0 不提供自动翻译或联网补全。

## 9. 安全边界

扫描不执行工具、安装程序或文档命令，不连接 MCP，不修改客户端配置，不删除或移动被盘点文件。用户主动导出、改变本工具设置或创建快捷方式时才写相应文件。

1.0 不提供启用、禁用、卸载和自动安装。未来涉及这些动作时，必须先展示具体变更，取得确认，并备份配置。

## 10. 验收要求

- 双击 EXE 可独立打开，不依赖 VS Code 或源码目录。
- 六类记录有准确路径与明确发现情况。
- 点击卡片进入详情，返回保留筛选。
- 新增文件后手动刷新和自动更新均能反映变化。
- 说明来源可核对；缺失说明明确提示。
- 设置可保存并读取；扫描不改动被扫描文件。
- 左侧不存在重复目录入口；标签名称为“本地位置”。

## 11. 1.0 非目标

全盘无限扫描、任意客户端/包格式适配、运行健康检测、MCP 连接测试、跨用户/WSL/远端盘点、云端同步、自动升级、自动翻译与卸载均不在本版范围。
