# AI工具管理器 1.0

版本号：1.0.0
计划标签：v1.0.0
日期：2026-10-18

这是从前端原型和内部开发版本整理的第一个正式版本基线。仓库与远程发布状态以 GitHub 实际页面为准，本文不代表已经上传成功。

## 主要能力

- 六类本地工具盘点：Skills、MCP、插件、GitHub/源码、独立软件、下载文件。
- 以证据描述状态，区分文件、配置、禁用标记、安装登记与尚未检测的运行情况。
- 卡片库、分类/搜索/客户端筛选与分页；点击整张卡片进入独立详情页。
- 本地文档说明、原文阅读、本地位置、路径复制和安全的文件夹定位。
- 手动刷新、应用打开时自动更新、最近变化与便携设置保存。
- 由用户主动创建桌面快捷方式；可导出 JSON/CSV。

## 运行

在 Windows 10/11 上双击发布包中的 AI工具管理器.exe，无需 VS Code、Node.js 或 .NET SDK。系统需具备 WPF/.NET Framework 与 Windows PowerShell 5.1。程序未做数字签名。

源码构建和测试方法见 README 与技术说明书。发布包应同时提供 EXE、源码与 SHA-256 校验值；编译产物不放入源码历史。

## 已验证与边界

扫描测试、原生界面/监听集成测试和脱离源码的 EXE 启动均纳入验证。Windows 11 当前环境实测；Windows 10 与不同企业策略仍需补充验证。

自动更新仅在软件打开且启用时生效。缺少本地文档时提供类型引导，不编造具体工具说明。不会修改客户端配置、连接 MCP、执行工具或自动安装/卸载。
